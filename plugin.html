Export Uncaptured Portals

Uno script per IITC (Ingress Intel Total Conversion) che legge i portali già caricati sulla mappa Intel, tiene solo quelli non ancora catturati da te, ed esporta un file JSON — lo stesso formato che il tool si aspetta in caricamento.

Gira interamente nel tuo browser: nessuna chiamata a endpoint non ufficiali oltre a quelle che IITC fa già normalmente per disegnare la mappa. Non serve nessun account, nessuna chiave, nessun server.

Scarica il plugin (.user.js)

Installazione

  1. Installa un gestore di userscript nel browser, se non ce l'hai già: Tampermonkey (Chrome, Edge, Firefox, Safari) è il più diffuso.
  2. Clicca "Scarica il plugin" qui sopra: Tampermonkey riconosce il file .user.js e apre automaticamente la schermata di installazione. Conferma con "Installa".
  3. Apri la mappa Intel di Ingress (intel.ingress.com) — il plugin è già attivo, comparirà una voce in più nella barra degli strumenti in alto.
  4. Scorri la zona che ti interessa a zoom 15 o superiore — IITC carica i dati completi dei portali solo a quel livello di zoom in su.
  5. Clicca "Export non-catturati" nella toolbar: scarica un JSON con tutti i portali non catturati attualmente visibili sulla mappa.
  6. Carica quel file nel tool per calcolare i percorsi.
Il plugin esporta solo i portali che hai effettivamente scorso a schermo, non un'area intera in automatico: è lo stesso limite di qualsiasi plugin IITC di esportazione, dovuto a come Intel carica i dati. Per aree grandi, panorama a tratti e unisci i file con l'altra pagina del sito.
